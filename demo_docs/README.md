# Demo Documents

Ready-to-use PDFs for demonstrating Limitless. Upload any of these to the app and start asking questions.

| File | Pages | Good demo questions |
|---|---|---|
| **bitcoin_whitepaper.pdf** | 9 | "How does Bitcoin prevent double-spending?" • "What is Proof of Work?" • "How are transactions verified?" |
| **attention_is_all_you_need.pdf** | 15 | "What is the Transformer architecture?" • "How does multi-head attention work?" • "What are the encoder and decoder components?" |
| **gpt3_language_models.pdf** | 75 | "How many parameters does GPT-3 have?" • "What is few-shot learning?" • "How does GPT-3 compare to GPT-2?" |

## How to use

1. Run `Run_Project.bat` (Windows) or `./start.sh` (macOS/Linux)
2. Open [http://localhost:5173](http://localhost:5173)
3. Drag and drop one of these PDFs onto the upload zone
4. Wait for status to show **Ready** (~10 seconds)
5. Start chatting — try the demo questions above!

> **Tip:** Enable ⚡ Agent mode to combine document search with live web search.
> Enable 🌐 All Docs after uploading multiple files to search across all of them at once.
